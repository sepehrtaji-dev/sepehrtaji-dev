## whoami

Hey! I'm **Sepehr** — an AI enthusiast who learns by building.

I'm interested in what happens *under the hood*: how models learn, how agents use tools, and how to turn an idea into a real, working project. I especially enjoy experimenting with **local AI**, so the model can run on my own machine instead of relying on a hosted API.

- 🧠 Exploring AI, machine learning, and neural networks
- 🛠️ Building **Nova**, a local-first AI agent powered by Ollama
- ♟️ Experimenting with chess engines and AI decision-making
- 🔬 Learning by creating small, practical ML experiments
- 🌱 Improving my Python skills and exploring lower-level programming

> *Curiosity is the roadmap. Building is how I learn.*
