## About

Hey, I'm **Sepehr** — an AI enthusiast who learns by building real projects.

I'm especially interested in what happens under the hood: how models learn, how agents use tools, and how software works beyond the surface. My current focus is **local-first AI** — building systems around models that can run on my own machine instead of depending on hosted LLM APIs.

- 🧠 Exploring machine learning, neural networks, and model behavior
- 🌌 Building **[Nova Agent](https://github.com/sepehrtaji-dev/Nova-agent)**, a local-first agent powered by Ollama
- ♟️ Experimenting with chess AI and decision-making
- 🔬 Building practical ML projects to learn from real data
- ⚙️ Learning C/C++ and low-level programming concepts
- 📐 Strengthening the math behind AI, one concept at a time

> *Curiosity sets the direction. Building turns it into understanding.*
